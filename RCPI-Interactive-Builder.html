Load an existing item

Paste an item's JSON, or the HTML of a page or item from a course (HTML view). Every item found is loaded into its section. If a page has several items of one type, only the first loads, so paste the others separately. The item loads into its section for editing and replaces what is currently in that section.

Instructions

Open this tool in a different tab or window to the course you're working on.

Building

  1. Choose an item type from the Item menu at the top (or type in the search box and press Enter). Only that item shows.
  2. Fill in the form. The live preview updates as you type.
  3. Set the item ID fields (descriptor, module, week, page, number).
  4. Use the copy button, then paste into a content row on your course page. Use the code button if you are pasting into the HTML view.

Notes

  • The item shows as a grey placeholder in the editor and runs in the learner view.
  • The runtime file rcpi-interactives.js must be loaded by the course template.
  • Hotspot placement: load the real image from your computer to place icons. It is only used for placement. The image URL field is what the learner sees.
  • Copied item code hides correct answers and answer feedback (switch at the top). This only stops casual viewing of the page code. Anyone who can read the page code and script can decode them. JSON copies are always readable, so keep them private.
  • Audio needs a transcript. Video and audio from the media library need their URL (direct file or embed).
  • Your work autosaves in this browser only. Use Copy JSON, then Paste JSON or Load, to move work between computers.
