      Note
      • The image picker copies an image directly to the clipboard. There may be a slight delay as it compresses the file.
      • This can be used to replace the image in placeholder by:
        • Clicking on the image placeholder in the course page.
        • Pressing Ctrl+V (or Cmd+V on Mac) to paste the image.
      • You may also delete the placeholder image by clicking the image and pressing backspace or delete ONCE. Then Ctrl+V to paste the new image.
      • Header images will be cropped to a 4:1 ratio (eg. 1920px x 480px)
      Instructions

      Open this tool in a different tab or window to the course you're working on.

      Colour Theme

      Use the colour template button if you want to change the theme colors.

      • You may then paste the code into the HTML view of the your page. The HTML view should be EMPTY before pasting.

      Rows

      • Every pasted item should be within a content row in your html page.
      • Use the row buttons at the top to copy more rows for your HTML page. These can be pasted directly next to the + icons in your html page.

      Components

      1. Use the drop-down or filter to find your desired interaction.
      2. Use the buttons to add items, rows and columns or change icons as needed.
      3. Use the copy WYSIWYG or copy code button to copy the interaction to the clipboard.
      4. Go to the course page and paste into a content row. If you copied the HTML code you will need to use the HTML view.
